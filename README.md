# MiceGo™ Website — V1.0

**Positioning:** Corporate Experiences, Simplified.  
**Target domain:** `micego.in`  
**Status:** Homepage starter committed for development; not deployed.

## Local development
Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Included
- Responsive Next.js App Router homepage with React and TypeScript
- Premium navy, champagne and ivory visual system
- Six corporate experience categories
- Discover → Design → Source → Manage → Deliver → Measure process
- MiceGo-vs-fragmented-arrangements proposition
- SEO metadata and canonical domain setup
- CSS-generated abstract artwork; no external travel imagery

## Before production
1. Replace the temporary email-based form with a server-side validated enquiry API; current form does not persist leads or guarantee delivery.
2. Insert the final approved MiceGo logo and favicon.
3. Approve legal footer, privacy notice and business contact details.
4. Add sitemap, robots and social preview image.
5. Configure `micego.in` DNS, TLS, redirects and hosting.
6. Run accessibility, mobile, form, SEO, security and production-build checks.
7. Configure GitHub Actions and deployment environments.

## Frozen brand rules
- No airplane, globe, map, pin, mountain, suitcase, route or generic travel-agency imagery.
- Website and operating platform share the brand but connect through a controlled, versioned API boundary.
- GitHub is the engineering system of record.
- No Odoo. Accounting boundary is TallyPrime/Tally API through the platform's controlled adapter.
